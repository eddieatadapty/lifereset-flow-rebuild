# Life Reset Growth Audit

**Live → https://eddieatadapty.github.io/lifereset-flow-rebuild/**

Five ideas to turn more Life Reset users into subscribers, each built into a clickable version of Life Reset's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the reason they gave you | +15–20% CR to purchase |
| 02 | Let them in before you ask for anything | +10–15% CR to purchase |
| 03 | Put your 4.7 stars beside the button | +10–15% CR to purchase |
| 04 | One commitment, not seven | +5–10% CR to purchase |
| 05 | Make the second chance honest | +10–15% ARPU |

Every price, rating and feature comes from Life Reset's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Life Reset. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
